## Overview

The ISO 8583 connector provides APIs for parsing, encoding, and processing ISO 8583 financial transaction messages. It supports standard message formats used in ATM, POS, and payment gateway systems.

### Key Features

- Parse raw ISO 8583 message strings into structured records
- Encode structured data into ISO 8583-compliant messages
- Generate and decode byte streams for network communication
- Configurable message structures via external packager definitions
- Support for ISO 8583:1987 standard with extensible configuration
